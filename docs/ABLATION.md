## 3. 稳健性检验（防过拟合）

**分半一致性**（prompt v2 轮为例）：

| | 前半 | 后半 |
|---|---|---|
| 总体增益 | +7.5pp | +6.6pp |
| comparison | +15.4 | +12.8 |
| null | +17.3 | +20.9 |

增益在数据前后半高度对称复现；分 10 段检查每段均为正（+4.2 ~ +9.8pp）→ 判定为系统性行为改善，非局部过拟合。

## 4. 失败归因数据（改进的依据）

**基线失败解剖（619 个失败，占比 24.2%）**：

| 题型 | 失败数 | 检索没到 | 只到一部分 | 证据齐全仍错 |
|---|---|---|---|---|
| comparison | 301 | 39 | 149 | 113 |
| temporal | 247 | 32 | 146 | 69 |
| inference | 43 | 9 | 31 | 3 |
| null | 28 | 28（设计使然） | — | — |

**关键中间发现**：
- comparison 的检索命中率其实最高（Hits@10 = 88%），505 个基线失败中 **84% 是生成侧问题**（证据在 context 里却答 "Insufficient Information"）→ 引导出 prompt v2
- null 失败的 77% 是**单字符垃圾输出**（'M'/'S'/'J'）→ 引导出清洗规则
- 证据密度与正确率严格单调相关（最弱来源 1 段的题失败率 42.5%，5 段只有 12.5%）→ 引导出来源补强 v2
- 语料中 **98.2% 的 chunk 正文不含自身发布日期** → 引导出日期标注
