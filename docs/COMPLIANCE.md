## 3. "gold 文本出现在 prompt 中"的对照实验（排除隐性泄漏）

现象：部分 prompt 的上下文里自然包含答案文本（如证据文章中出现 "Sam Bankman-Fried"）。用对照实验证明这是**证据共现**而非注入：

| 分组（长答案 ≥8 字符） | gold 文本出现在 prompt 中的比例 |
|---|---|
| 证据命中组（答案所在段落被检索到） | **91.7%**（376/410） |
| 证据未命中组（答案段落未被检索到） | **27.5%**（119/432） |

出现率严格跟随证据是否被检索到（若为注入，两组应均为 ~100%）；残余 27.5% 为同名实体在其他文章中的自然提及。

## 4. 增强模块的信号来源

| 模块 | 使用的信号 | 来源 |
|---|---|---|
| 源覆盖 / 来源补强 | 题面点名的来源名（如 "as reported by X and Y"） | **题目原文** ↔ 语料 `source` 元数据 |
| 日期匹配 / 日期标注 | 题面点名的日期（如 "October 7, 2023"） | **题目原文** ↔ 语料 `published_at` 元数据 |
| 答案清洗规则 | 答案长度（≤1 字符） | 模型输出自身 |

所有信号均可在**不看任何标注**的前提下从题目原文与公开语料元数据中得到。
